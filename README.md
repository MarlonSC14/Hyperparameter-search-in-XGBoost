# Hyperparameter-search-in-XGBoost
This exercise has the objective to teach you how to work with XGBoost in a Google Colab environment. Specifically, how to make a hyperparameter search for a classficiation models using three specific metrics (precision, recall and auc).
The hyperparamter search is performed using bayesian optimization. As this is an introductory notebook, details on hyperparamters are not considered and we are limited only to creating and training XGB models, as well as performing the corresponding hyperparameter search.
